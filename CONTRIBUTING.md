# Como contribuir

Obrigado por ajudar a melhorar este guia. Contribuições úteis incluem corrigir erros, atualizar referências, esclarecer conceitos e adicionar exemplos que possam ser generalizados sem expor sistemas ou dados reais.

## Antes de abrir uma contribuição

1. Pesquise as issues existentes para evitar duplicatas.
2. Para mudanças maiores, abra uma issue primeiro e explique o problema que a mudança resolve.
3. Prefira uma alteração pequena, com escopo claro e fontes verificáveis.

## Envie uma pull request

1. Crie uma branch com um nome descritivo, por exemplo `docs/corrigir-referencia-slo`.
2. Edite os arquivos Markdown correspondentes em [`docs/`](docs/).
3. Atualize os links internos quando mover ou renomear documentos.
4. Confira a visualização Markdown do GitHub e verifique todos os links adicionados.
5. Abra a pull request usando o modelo do repositório e descreva o motivo da mudança.

## Padrões editoriais

- Escreva em português brasileiro, com linguagem direta, inclusiva e sem jargão desnecessário.
- Diferencie fatos documentados, resultados de pesquisa, avaliação editorial e recomendação.
- Prefira documentação oficial, pesquisa primária e fontes com data e metodologia explícitas.
- Para alegações de mercado, informe fonte, data e contexto; não apresente uma amostra como se representasse todo o setor.
- Não invente métricas, preços, níveis de adoção, badges, maturidade ou resultados.
- Compare ferramentas por contexto e limitações; não transforme conteúdo em publicidade.
- Use exemplos fictícios e remova credenciais, dados pessoais, URLs privadas e detalhes de clientes.
- Mantenha títulos descritivos, parágrafos curtos, listas quando ajudam a leitura e tabelas apenas para comparações.
- Não trate exemplos ou políticas do guia como prontos para produção.

## Checklist antes de enviar

- [ ] A mudança resolve um problema claro e mantém o foco em SRE.
- [ ] Afirmações novas têm fonte ou estão identificadas como avaliação.
- [ ] Links internos funcionam e links externos apontam para as fontes pretendidas.
- [ ] A página continua legível no GitHub e não contém informação confidencial.
- [ ] O índice foi atualizado se um documento foi adicionado, removido ou renomeado.

Ao contribuir, você confirma que tem o direito de enviar o material. A licença deste repositório deve ser definida por quem o mantém antes de aceitar contribuições públicas.
